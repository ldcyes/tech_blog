02 / What is inside

把论文主张拆成可检查的层

每个页面都区分 NVIDIA 报告事实、交互解释和工程推测。

Paradigm

Generative display stage

RGB 负责锚定内容、身份和边界；照片外观先验补充材质与照明表现。

Pixel space

RGB → RGB interface

不走有损 VAE latent 往返；但 pixel-space I/O 不等于所有内部特征都保持 4K。

Streaming

Causal, one-step inference

当前帧加过去状态，不等待未来帧；一次确定性前向进入显示管线。

Control

Structure / Tone / masks

开发者可控制模型子集、细节强度、色调强度和区域遮罩。

Evidence

Alignment + realism

DINOv2、LPIPS、albedo、normal、depth 对齐指标与独立照片真实感盲测互补。

Hardware

Compute is the constraint

154M 参数、8 ms、FP8 和 TMA 共同决定可行的空间分组、复用与内存路径。

04 / How to use this review

四步读法 / Four-step reading path

适合快速了解，也适合工程评审或 benchmark 复现。

建立直觉

先看中文版或英文版的 paradigm、system 和 streaming 章节。

核对指标

打开 benchmark 表，区分 content、structure 与 photographic realism。

看上游流程

阅读 PT/non-PT、albedo/normal/depth 和 estimator 的定义。

审慎外推

回到 limits：静态分数不能替代动态伪影、尾延迟与 OOD 测试。

Engineering boundary / 工程边界： 本站的架构候选、算力利用率和显存解释均明确标注为推测。报告没有公开网络层数、token 化、时域状态容量、训练集和完整动态失败率；请把交互模拟当作推理工具，而不是 NVIDIA 的实现披露。

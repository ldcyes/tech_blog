REAL-TIME GENERATIVE RENDERING

DLSS 5 不是更聪明的超分，而是显示前的生成式着色器。

它把传统渲染帧作为不可放弃的几何与内容锚点，再用从真实照片学到的外观先验重写材质与照明表现。核心突破是把一次、确定性、像素空间扩散压进实时帧预算；核心风险则是“看起来更真实”并不等于“更物理正确”。

一句话工程判断：DLSS 5 是一个后置、renderer-conditioned、causal 的 154M Transformer。它扩大了实时渲染的“外观带宽”，但没有扩大场景的真实信息量；上游缺失的几何、错误的遮挡和退化边缘仍然无法被可靠恢复。

NVIDIA 的中心论点：DLSS 5 在保持作者内容和结构的同时，达到与 GPT Image 2 相当、优于 Gemini 3 Pro 的感知照片真实度，并在单张消费级 GPU 上实时运行。
从系统角度，它是以 RGB、运动矢量、历史状态和控制量为输入的 learned post-process；训练期使用 albedo / normal / lighting 一致性约束，但部署时不需要这些 G-buffer。
报告没有公开网络层数、token 化/窗口、训练集规模、蒸馏损失、时域状态尺寸、不同 GPU 性能、端到端延迟或失败率分布；因此“产品化可用”仍需独立动态测试验证。
01 / PARADIGM SHIFT

从重建目标，转向生成最终外观

DLSS 1–4 的目标仍由高成本渲染参考定义；DLSS 5 首次不再逼近一个传统渲染目标，而是在内容保持集合内选择“更像照片”的结果。

RECONSTRUCTION

Super Resolution / Frame Generation / Ray Reconstruction

  • 估计更多像素、更多帧或更多光线的渲染结果
  • 参考目标来自传统 renderer
  • 上限受 renderer 可表达与可模拟内容约束
  • 主要价值：更低成本逼近更高渲染预算
VERSUS
GENERATION

DLSS 5 / 3D-Guided Neural Rendering

  • 直接生成最终显示 RGB
  • 目标来自照片外观统计先验
  • 传统帧负责“是什么”，模型决定“看起来怎样”
  • 主要价值：补入实时资产与光传输难以承担的外观线索

论文的概念公式

在所有保持输入场景属性的图像集合 C(r) 中，选择照片分布概率最高的结果：
fθ(r) ≈ arg max pphoto(x), x ∈ C(r)。这是意图描述，不是公开的实际训练目标。

关键边界

C(r) 不是运行时硬约束。身份、结构、材质和光影组织的保持，依赖训练监督形成的统计倾向；论文明确承认每次生成变化都存在漂移风险。

03 / STREAMING

为什么必须逐帧因果，而不是视频分块

离线视频模型通过 K 帧联合上下文换取稳定性，但会引入 K−1 个帧间隔的额外等待，并让工作集随 K 增长。拖动 K 观察差异。

分块额外等待33.3 ms
相对工作集3×

DLSS 5 的 frame-wise 路径对应 K=1：不等待未来帧，峰值推理内存对序列长度为 O(1)。这不代表没有模型执行延迟。

Chunk-based

K 帧缓存后联合前向；吞吐友好，但交互等待和显存随 K 上升。

DLSS 5 frame-wise

一帧输入、一帧增强；历史被压入 carried state，不保存无限序列。

04 / ART DIRECTION

不是一个“真实度”旋钮，而是可定向的外观映射

当前系统提供少量 curated appearance models，并把结构与色调拆成近似高/低空间频率控制；遮罩可限定增强发生在哪里。

抽象信号演示 · 非 DLSS 5 实际输出

Structure

控制局部对比、环境遮蔽、反射、次表面散射等高频外观细节。

Tone

控制大尺度亮度、颜色响应与环境/间接光照等低频变化。

零强度配置为无增强输入，单位强度应用完整学习变换。实际控制量作为 learned conditioning 输入，不是推理后的简单滤镜。

05 / EVIDENCE

109 个场景上的证据，证明了什么

指标分成两类：照片真实感由盲测衡量；内容/身份和结构保持由 DINOv2、LPIPS 及估计出的 albedo / normal / depth 衡量。两类不能互相替代。

06 / BUDGET

8 ms 意味着什么

报告只给出 RTX 5090、3840×2160：模型约 8 ms、峰值显存 731 MB。下面用像素数线性缩放作粗略预算实验；推算值不是 NVIDIA 实测。

共享 GPU 的含义

这 8 ms 要与游戏 simulation、geometry、base rendering、RT/PT、SR/RR/FG 等竞争同一 GPU 预算。它不是“免费”的后处理。

07 / LIMITATIONS

最重要的局限，不在平均分数里

报告在 §5 对边界的表述相当明确：DLSS 5 优化的是照片外观概率，不是物理真值；它宁愿保留坏输入，也不愿随意发明替代内容。

FUNDAMENTAL

感知真实 ≠ 物理正确

它不收敛到 renderer-defined ground truth，也不补做被省略的光传输。照片统计偏好可能制造“熟悉的真实感”，却偏离场景真实光源与材质。

INPUT-BOUND

信息不存在，就不能可靠恢复

缺失几何、错误身份、严重 aliasing、弱边界和损坏细节可能被保留或放大。模型输出 RGB，不修改 geometry、scene state 或 G-buffer。

DOMAIN

只针对照片写实

当前目标不适合 voxel、插画、卡通等强风格化视觉语言。追求照片真实可能直接破坏原有 art direction。

GENERALIZATION

分布漂移仍是未知数

不同 shading convention、材质分布、场景统计或 artifact pattern 可能超出训练分布。报告未给系统性 OOD 压测。

TEMPORAL

“训练为稳定”不是零伪影保证

运动矢量与 carried state 提供时间对应，但报告没有公开动态视频指标、长序列漂移、disocclusion、粒子/透明材质等 corner case 的分布。

EVALUATION

基线对比并非同类实时系统

GPT Image 2 与 Gemini 3 Pro 是托管离线编辑模型；对比证明专用模型的实时/对齐优势，但不能替代与传统后处理、实时 neural rendering 或人工优化的横向比较。

我的判断：“生成式着色器”会成为新管线层，但第一代产品最可能先在皮肤、头发、植被、织物和局部间接光等高统计规律区域创造价值。真正决定可用性的，不是静态截图峰值，而是低置信场景的自动退化、遮罩工具成本、跨镜头一致性与性能尾延迟。

术语速查

3D-guided neural rendering由传统渲染帧严格锚定内容的生成式最终着色阶段。
Grounded conditioning用像素对齐 RGB 与运动矢量约束生成，不是用文本描述猜场景。
One-step diffusion每帧只做一次确定性推理，不进行多步随机采样。
Pixel-space不经过有损 VAE latent 往返，直接 RGB → RGB。
Carried temporal state从过去帧延续的有限状态；论文未公开具体实现和容量。
TMABlackwell Tensor Memory Accelerator，用于高效搬运全局与片上数据。
评测方法的三个细节

所有输出为 3840×2160；DINOv2 特征比较先缩放到 672×378，image LPIPS 在完整 4K 上计算。结构指标依赖一个同时处理输入与输出的单一 estimator 提取 albedo / normal / depth。PT 与 non-PT 子集场景不同，因此差值只能描述，不能解释为 path tracing 的因果收益。

论文最诚实的一句话可如何转述

作者明确说明：运行时没有机制强制内容保持；一致性监督只在训练期起作用，每个生成变化都带来偏离作者场景的风险。这是理解 DLSS 5 产品边界的关键。
